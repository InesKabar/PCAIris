# PCA Iris

A Python project that explores the Iris dataset using data visualization and Principal Component Analysis (PCA).

## Project Overview

The project uses the Iris dataset from Scikit-learn and visualizes the three Iris flower species in a 3D plot.

The dataset contains four features describing the flowers:

- Sepal length
- Sepal width
- Petal length
- Petal width

The project prepares the data for PCA and explores the relationships between the different Iris species.

## Technologies

- Python
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

The project uses the built-in Iris dataset provided by Scikit-learn.

## Visualization

The Iris dataset is visualized in a 3D plot with the three species:

- Setosa
- Versicolour
- Virginica
